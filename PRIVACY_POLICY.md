# Privacy Policy (for this repository)

This document covers **this GitHub repository only** — a small public archive of one coding-agent session and a few documentation files. It is not Rankelo's product privacy policy.

## Data collected by this repository

None. This repository contains static Markdown files. It does not run any service, does not have a backend, and does not collect, store, or process personal data on its own. Standard GitHub platform data (stars, clones, traffic analytics, issue/PR activity) is governed by [GitHub's own Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement), not by us.
