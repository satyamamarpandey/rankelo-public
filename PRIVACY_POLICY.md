# Privacy Policy (for this repository)

This document covers **this GitHub repository only**, a small public archive of one coding-agent session and a few documentation files. It is not Rankelo's product privacy policy, which is a separate document covering the live product itself; see below for where to find that.

## Data collected by this repository

None. This repository contains static Markdown files, nothing more. It does not run any service, does not have a backend, and does not collect, store, or process personal data on its own. Standard GitHub platform data, such as stars, clones, traffic analytics, and issue or pull-request activity, is governed by [GitHub's own Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement) rather than by anything published here.

## About the session transcript

`rankelo_ef_coding_session.md` is a redacted excerpt of a real local development session. Before publication, it was checked for, and had removed, API keys, tokens, passwords, cookies, credentials, and any private infrastructure detail that would create a security risk.
